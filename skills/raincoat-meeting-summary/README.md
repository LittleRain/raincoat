# raincoat-meeting-summary

把会议逐字转写或多人讨论记录整理为议题结论、行动项和关键决策。原文缺失的负责人、日期和决策人标为待确认。

## 安装与使用

下载整个 `raincoat-meeting-summary/` 目录，按宿主的本地 Skill 安装方式放入技能目录，保留目录名与内容。安装路径由宿主决定，不要求克隆 Raincoat 仓库。若宿主没有 Skill 加载功能，可将 `SKILL.md` 作为任务说明提供给它，但这不等于原生集成已验证。

在宿主中选择 `raincoat-meeting-summary`，或让它读取该目录的 `SKILL.md`，然后发送：

> 请整理下面的会议转写，提取结论、行动项和关键决策。原文没确定的不要补全。

输入可直接粘贴文本；要读取本地文件时，宿主需要文件读取权限。输出默认是对话中的 Markdown，不会自动创建待办、发消息或访问企业微信。

## 依赖与兼容性

纯文本 Skill，无脚本、CLI、网络、账号或付费服务依赖；模型推理由所选宿主提供，费用与文本处理方式遵从该宿主配置。

| 环境 | 状态 | 验证范围 |
| --- | --- | --- |
| Codex 当前会话 / macOS | 已做人工样例复核 | 合成输入的结构化提炼；未做全新安装与自动发现测试 |
| Windows | 未实测 | 无操作系统专用调用；仍需实际宿主验收 |
| 其他支持 Agent Skills 的宿主 | 未实测 | 格式兼容不代表行为和安装均已验证 |

## 示例与验收

[合成输入](examples/transcript.md) → [参考输出](examples/summary.md)。检查点：不替相对日期补年份；不把建议当承诺；不补上线日期；每条行动与决策能回到原文。参考输出是人工整理示例，不是自动化集成测试结果。
