02校验与证据

两级判定：阻塞（原 FAIL）会挡住迁移，必须先修；提示（原 WARN）只影响质量。每条结论都带 文件:行号 证据。规则定义在 rules.json，可自行增删。

03生成安装指令

选一个 skill + 目标 agent，生成可直接发给那个 agent 的指令。指令里已钉死来源路径、安装位置、安装方式、备选方案与前置校验结论，目标 agent 只剩执行。

输出形式
还没有生成。选一个 skill 和目标 agent，点「生成」。
已复制

04重复与冲突

同名不等于重复。先分清同名异物（不同来源恰好重名，硬合并会出事）与真重复（同一份被复制到多处），再看两边是否还都在生效。每组都带处方：留哪一份、为什么、能不能自动做。

05适配表与开关机制

agent 适配表（agents.json）与每个 agent 的启用/禁用开关落点。实测下来四个 agent 四种机制、两种粒度，没法统一，所以逐个声明。
