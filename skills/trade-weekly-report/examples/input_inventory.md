# 历史入口输入文件清单

本清单对应 [legacy 入口](../scripts/legacy/README.md)。当前默认入口的六文件合同见 [README](../README.md)。

将以下文件放入同一个输入目录，文件名允许带日期或周次后缀，但应满足对应 pattern：

- `整体数据*`
- `区分行业*`
- `分行业*流量*`
- `分行业*内容*`
- 可选：`*天马推荐商品卡*`
- 可选：`*商城首页feed*` 或 `*分商城首页feed*`
- 可选：`*商品*流量*商家*`
- 可选：`*商品*体裁*商家*`
- 可选：`*UP*list*` 或 `头部*UP*`（至少包含 `店铺id` / `商家ID` / `up_mid` 之一，优先 `店铺id`）

验证使用 `tests/generate_fixture.py` 生成的合成数据，命令见 [测试说明](../README.md)。旧业务样本已归档至仓库外，不作为公开验证输入。
