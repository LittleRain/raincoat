# 企微面聊纪要分析

把企业微信「记录面聊」的逐字转写（或任意带发言人的会议讨论记录），一键整理成可回顾、可执行的会议纪要。

## 什么时候会用到

- 同事用企微「记录面聊」录了一段线下面聊，生成了一堆逐字转写，你想快速拿到结论和待办。
- 粘贴一段带发言人（如「张三：……」「李四：……」）的多人讨论记录，想提取行动项、派活。
- 想复盘一次会议：谁拍了板、依据是什么、还有哪些没定的事。

典型开口：**"分析面聊"**、"整理面聊纪要"、"把这堆记录整理成待办"、"提取这次会议的行动项"。

## 它会做什么

对输入的逐字转写做三层提炼，输出一份固定格式的纪要：

1. **议题与结论** —— 按议题归拢，每条写清结论、背景要点和待定项。
2. **行动项（待办）** —— 负责人 + 截止时间 + 原文依据。
3. **关键决策** —— 决策内容 + 拍板人 + 依据 + 是否有分歧。

对口语化的原始转写会先清洗（去口头禅、口语转书面语），并保留承诺、日期、数字等关键信息。

## 前置条件

无。直接粘贴面聊转写文本即可，不需要任何工具或凭证。

## 注意

- 声纹识别可能有误（错别字、发言人混淆），Skill 会尽量标注而非当事实。
- 原文没提到的负责人、时间，会写"待确认"而非编造。
- 它处理的是"逐字转写/讨论记录"这一类文本，不适合给已排好版的结构化文档做美化和排版。
